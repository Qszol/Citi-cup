# 印章识别与鉴别算法项目（花旗杯）
## 一、项目概述

本项目面向商业银行信贷业务场景，针对各类扫描件或拍摄文档中的印章信息，开展自动化的图像分析与风险识别研究。
项目目标是通过算法手段，实现对印章的定位检测、真伪鉴别以及一致性验证，为信贷风控提供辅助决策支持。

本项目为花旗杯竞赛算法组核心工程，由算法组主导开发，并与软件组、商业组协同完成。

## 二、任务定义

算法组的整体任务分为三个相对独立、但可协同使用的子模块：

印章检测（Stamp Detection）
从复杂版式、多背景的文档图像中，自动定位并裁剪印章区域。

印章真伪鉴别（Forgery Identification）
对单个印章图像进行细粒度分析，判断其真实性，并输出概率化判别结果。

印章一致性验证（Consistency Matching）
比较扫描印章与参考印鉴，判断二者是否一致，并输出一致性概率。

各模块既可单独评估，也可串联形成完整处理流程。

## 四、数据说明

项目数据主要来源于信贷业务相关的扫描件或拍摄文档图像。

data/raw/
存放原始采集数据，仅用于备份和参考，不直接用于模型训练。

data/processed/
存放经过清洗、预处理和标注后的数据，用于模型训练与评估。

数据需按照统一规范进行整理与标注，确保不同任务之间的数据一致性与可复用性。

## 五、算法模块职责划分

detection/
负责印章区域的定位与裁剪，为后续任务提供输入。

forgery/
负责对单枚印章进行真伪判别，重点关注细粒度纹理与结构特征。

matching/
负责印章之间的相似性度量与一致性判断。

各模块需明确输入输出格式，避免隐式依赖。
